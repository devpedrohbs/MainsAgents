# Edição automática — motion dinâmico com Remotion (Frente B)

Data: 08/10/2026. Escopo: ampliar a edição automática existente (FFmpeg corta silêncios → Remotion anima) com motion guiado pela fala: transcrição com tempos por palavra → ênfase da voz MEDIDA no áudio + inferências do texto → plano temporal editável → composição Remotion → revisão → render integrado. Remotion/@remotion/* continuam em 4.0.534 (nenhuma dependência nova).

## Fluxo (onde cada parte vive)

| Etapa | Implementação |
|---|---|
| Tempos por palavra | `editorial-transcribe.mjs`: whisper.cpp agora roda com `-dtw base` (modelo oficial verificado) e `parseWhisperJson` devolve `words` (tokens sub-palavra unidos; início = tempo DTW do 1º token). Gravado no cache de transcrição (`editorial-media.mjs`). Transcrições antigas sem `words` → tempos **estimados** dentro da frase, rotulados. |
| Ênfase medida | `editorial-motion-plan.mjs`: FFmpeg extrai PCM 8 kHz → energia (10 ms), pausas medidas, F0 por autocorrelação (75–400 Hz, correção de oitava), alongamento. Por palavra: volume relativo à vizinhança (±4 s), altura em semitons vs. mediana do falante, pausa antes, alongamento. `alignWordsToVoice` corrige palavras que o reconhecedor colocou dentro de uma pausa medida. |
| Inferências do texto | palavras-chave (pt/en), números, pontuação enfática e até 6 frases-chave do agente editor — usadas só se foram **ditas** (casamento literal na transcrição; o resto é ignorado). Sempre `source:'inferred'`. |
| Plano editável | `buildMotionPlan` → cues `punchIn` (aproximação), `kineticText` (texto animado), `keyPoint` (cartão com `split` ou `motion-focus` e retorno suave à câmera). Cada cue: âncora na gravação (`sourceStart/sourceEnd`), tempo no editado (`start/end`), `reason` legível, `signals` com origem (`measured`/`inferred`), `strength`, `scale`, `layout`, `timing` (`words`/`estimated`) e SFX opcional (`kind`, `gainDb`, `ducked`). |
| Densidade | presets `subtle/balanced/intense` (máx. por minuto, distância mínima, intervalo entre mudanças de layout, limite de SFX por minuto, limiar de ênfase); bordas (0,5 s iniciais e 1 s finais) e janelas de título/tarja/CTA reservadas. `off` desliga. |
| Remapeamento após cortes | `normalizeMotion` (chamado por `validatePlan`) recalcula SEMPRE `start/end` a partir das âncoras e dos trechos mantidos; cue cujo trecho foi cortado sai; nunca atravessa um corte. Ajustar cortes na revisão mantém a sincronia. O motion entra no `planHash` aprovado. |
| Render | `remotionAnimations(plan)` passa `motion`; `resolveAnimations` (adaptador) converte para frames com o fps real do vídeo cortado (`resolveMotionProps`). Composição `remotion-video/Motion.tsx` + `layout.ts`: câmera com recorte focal e punch-in, cartões (painel + texto cinético + número animado com sufixo), texto cinético palavra a palavra com destaque, tudo função de `useCurrentFrame()`/`interpolate()`/`Easing.spring` (sem CSS transition, sem aleatoriedade), `<Sequence premountFor={fps}>` por cue. Áreas seguras (6% laterais, 8% topo, base 10% / 20% no 9:16), geometria própria para 9:16, 16:9 e 1:1. |
| SFX | sintetizados localmente e de forma determinística (`whoosh`, `pop`, `tick`; ruído filtrado/senoides; sem arquivos de terceiros → sem licença a observar). Ganho planejado ≤ −10 dB (−4 dB extra sobre fala) e mix FFmpeg com `sidechaincompress` pela própria voz (ducking dinâmico), `amix normalize=0` (a fala não é atenuada). Só para áudio mono/estéreo; caso contrário o áudio original é preservado sem SFX. |
| Integração | Produção: `editPreferences.motion` (padrão `balanced`), o agente editor pode devolver `highlights`; `planSmartEdit` chama `media.motion` (rota `POST /api/content/media/motion`) e inclui o motion no plano; falha do motion não bloqueia a edição (vira observação). Export avançado chama o Remotion também quando só há motion (`needsAnimation`). |
| UI | “Movimento na edição” (Equilibrado/Sutil/Intenso/Sem motion) em `ProductionDialog` (etapa de gravação) e `RecordedEntry` (vídeo já gravado), só no modo automático. Em “Conferir edição”, seção **Movimento**: cada momento com tempo no editado, tipo, evidência (“voz medida”, “voz medida + texto”, “só texto”), motivo, efeito sonoro/tela dividida, “Ouvir no bruto”, desmarcar para remover, trocar intensidade (gera de novo com os cortes atuais) ou “Sugerir movimento” em versões sem motion. Exportar a versão ajustada aplica tudo. |

## Limites reais

- **Prosódia real não validada.** Toda medição foi feita em fixtures sintéticas: tons harmônicos (testes unitários/integração) e a voz offline do Windows com SSML de ênfase (amostra). Nenhuma gravação humana foi usada; os limiares (+3 dB, +2,5 st, pausa ≥ 0,35 s, alongamento ≥ 1,6×) precisam de calibração com vídeos reais.
- **Atribuição por palavra é aproximada.** Mesmo com DTW, o whisper.cpp base erra ~0,2–0,5 s em palavras isoladas; na amostra a ênfase SSML em “nunca” foi medida na palavra vizinha (“é”). A janela da cue (frase) cobre o trecho, mas o punch-in pode começar levemente antes/depois da palavra exata.
- Reconhecimento erra palavras (amostra: “revise” → “lhe vai”); frases-chave do agente que não casam literalmente são ignoradas (comportamento honesto, mas perde o destaque).
- Sem detecção facial: o ponto focal é fixo no terço superior central; rostos fora dessa região podem ser cortados no split/punch-in. Texto fica fora do terço focal e dentro da área segura.
- SFX só sintéticos (3 tipos); áudio com mais de 2 canais fica sem SFX.
- Prévia no app = lista revisável + “Ouvir no bruto” + vídeo exportado; não há player Remotion ao vivo antes de exportar.
- Transcrições em cache feitas antes desta versão não têm `words`: o plano usa tempos estimados (rotulado) até uma nova transcrição.

## Como acessar no app

Conteúdo → Produção → etapa de gravação (ou “Vídeo já gravado” no chat do conteúdo): escolha **Automática** e **Movimento na edição**. O plano aparece na mensagem do Editor de Vídeo (“Motion equilibrado: …”); depois, “Conferir edição (bruto × editado)” → seção **Movimento** para revisar/remover/trocar intensidade e “Exportar versão com meus ajustes”. Para o app instalado é preciso gerar novo pacote (`npm run desktop:dist`) — não foi feito aqui.
