# Usability refinement — September 2026

The visual identity stays neutral and quiet: light/dark glass surfaces, the existing mascot, and the Canvas post-it/browser objects. The refinement focuses on deliberate decisions and continuity of work.

- Palette: paper `#fafafa`, ink `#111111`, muted `#6b6b6b`, divider `#e5e5e5`, action blue `#2f6feb`. Use the existing dark equivalents.
- Typography: retain Inter/system sans. Body text uses 14px and a comfortable line height; titles use 20–24px. Supporting labels use sentence case.
- Layout: left-aligned page titles and toolbars; quiet task columns; lists for conversations and agent choices. Each screen has a clear next action. Avoid adding dashboard decoration.
- Flow: Create → choose object → configure → continue. New conversations and Canvas context explicitly choose an agent. Creating an agent during another flow resumes that flow.
- Settings: separate interface, AI connections, data, account and help. Keep backup review visible and provider connection steps actionable.
- Conversation history: filter by agent, show a message preview, open, rename or confirm deletion. Running sessions cannot be deleted from this view.
- Chat: fixed composer, scrollable history, latest-message shortcut, drafts separated by agent/session. Enter sends; Shift+Enter inserts a line break.
- Accessibility: dialog focus stays contained and returns to its trigger; Escape dismisses. Small screens wrap toolbars and keep actions reachable. Respect reduced motion.

Review against the brief: preserve the current front end rather than adding a new palette, decorative hero, animation library or uniform card kit. Minimalism here means fewer implicit actions and fewer competing controls.
